# Olist E-Commerce Data Analysis | Python

## Project Overview

This project analyzes Brazilian e-commerce data from Olist using Python and Google Colab.

The analysis focuses on customer behavior, order performance, delivery times, payment methods, product categories, and customer satisfaction. Exploratory data analysis and statistical methods were used to identify patterns and relationships within the data.

## Tools & Technologies

- Python
- Google Colab
- Pandas
- NumPy
- Matplotlib
- Seaborn
- Plotly
- Statistical Analysis

## Analysis

### Data Preparation

- Loaded and explored multiple Olist datasets.
- Checked data types, missing values, and duplicate records.
- Prepared the datasets for exploratory and statistical analysis.
- Combined relevant datasets to investigate relationships between orders, customers, products, payments, delivery, and reviews.

### Exploratory Data Analysis

The project examines:

- Order and sales performance
- Product categories
- Payment methods
- Delivery times
- Customer satisfaction
- Relationship between price and delivery time
- Relationship between delivery performance and customer reviews

### Statistical Analysis

Statistical methods were applied to investigate relationships and differences in the data, including:

- Correlation analysis
- Welch's t-test
- One-Way ANOVA
- Chi-square test of independence

## Key Findings

The analysis examines how delivery performance, order characteristics, payment methods, and product-related factors relate to customer satisfaction and e-commerce performance.

The project also compares customer satisfaction between orders delivered on time and orders delivered late.
